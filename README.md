# Resume Website

An open source portfolio template based on the latest Saud Website layout and features, with neutral assets, fictional content, and commented customization settings.

The complete site is in [`template/`](template/). Start with its [setup and customization guide](template/README.md).

```sh
cd template
npm run dev
```

Includes separate desktop/mobile layouts, project and experience cards, certificate previews, a printable résumé, a local content editor, and an optional static journal with search, topic pages, source links, RSS, and sitemap.

Publish the contents of `template/` as your site root. Customize `my-data/config.js` and `my-data/portfolio_data.json`, then rebuild the journal before publishing your own version.

Originally created by [Saud Alotaibi](https://github.com/SaudMonsour).
